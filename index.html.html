Selamat Datang di Platform Asesmen Biologi

Sistem penilaian berbasis komputer ini dirancang untuk mengukur tingkat penguasaan konsep Biologi pada materi Sel dan Sistem Gerak Manusia. Hasil penilaian pilihan ganda akan dihitung secara otomatis dan langsung memberikan umpan balik ketuntasan belajar Anda.

Petunjuk Pengerjaan Asesmen

  1. Isi Formulir Identitas dengan benar (Nama Lengkap, Kelas, dan Nomor Absen).
  2. Pilih salah satu materi ujian (Materi Sel atau Sistem Gerak Manusia).
  3. Setiap paket ujian terdiri atas 20 Soal Pilihan Ganda dan 5 Soal Uraian (Essay).
  4. Waktu pengerjaan dialokasikan selama 45 Menit dan berjalan otomatis.
  5. Gunakan navigasi soal untuk menandai jawaban ragu-ragu atau berpindah nomor.
  6. Tekan tombol "Selesaikan Ujian" jika sudah selesai sebelum waktu habis.
Sistem otomatis menyimpan jawaban Anda secara langsung di perangkat browser.

Penilaian Uraian / Essay Guru

Panduan Website & Publikasi Online

Cara Menggunakan Website:

1. Mode Siswa: Siswa memilih materi, mengerjakan 20 PG & 5 Uraian. Setelah selesai, skor PG dihitung otomatis dan tersimpan.

2. Dashboard Guru: Akses via menu atas dengan PIN default: 1234. Guru dapat menilai essay, memfilter kelas, dan mengekspor nilai ke file Excel/CSV.

Cara Mempublikasikan Website agar Online Gratis:

  1. Opsi 1 (Netlify Drop - Paling Mudah): Simpan kode ini sebagai index.html. Buka app.netlify.com/drop, drag-and-drop file tersebut. Website langsung aktif online dalam 10 detik!
  2. Opsi 2 (Vercel): Upload file ke akun GitHub Anda, lalu hubungkan ke Vercel untuk deployment otomatis.
  3. Opsi 3 (GitHub Pages): Buat repositori publik di GitHub, upload index.html, lalu aktifkan GitHub Pages pada menu Settings > Pages.
